# MyClient — скелет Fabric-клиента (1.21.1)

## Что тут есть
- Gradle/Loom проект под Fabric 1.21.1, Java 21
- Система модулей: `Module`, `Category`, `Setting` (Bool/Double/Enum), `ModuleManager`
- ClickGUI (`ClickGuiScreen`) с плавными анимациями раскрытия панелей и переключения модулей
- Три рабочих модуля-примера:
  - `Fullbright` — чисто клиентская опция яркости
  - `AutoSprint` — автобег через штатный `setSprinting`
  - `Tracers` — рендер линий до сущностей через `WorldRenderEvents`
- Биндинг Right Shift на открытие GUI

## Что НЕ доделано и требует твоих рук
1. **Клики по ClickGUI не обрабатываются** — `mouseClicked` в `ClickGuiScreen` пустой.
   Нужно посчитать хитбоксы панелей/строк в `render()`, сохранить их (например,
   в `List<Rectangle>` с привязкой к модулю) и проверять в `mouseClicked`.
2. **Module#setEnabled** не отписывает тик-листенер корректно — там TODO,
   потому что лямбда `v -> onTick()` создаётся заново при каждом вызове и
   не равна себе для `remove()`. Нужно хранить `Consumer<Void>` как поле класса
   и передавать ту же ссылку в subscribe/unsubscribe.
3. **Tracers** — векторная арифметика упрощена, при первой сборке в Fabric 1.21.1
   могут потребоваться небольшие правки под точный API `RenderLayer.getLines()`
   (формат вершин там включает нормаль — возможно понадобится `.normal()` в builder).
   Это нормально доводится за один цикл компиляции/фикса.
4. **Конфиги** — сохранение настроек модулей между запусками не реализовано,
   нужен JSON-сериализатор (Gson, он уже есть в classpath Minecraft).

## Как собрать
```
./gradlew build
```
Собранный jar будет в `build/libs/`, кидаешь в `mods/` рядом с Fabric API.

## Как добавлять новые модули
1. Создать класс в `impl/module/modules/<категория>/`, унаследовать `Module`
2. Переопределить нужные методы (`onEnable`, `onDisable`, `onTick`, `onRender`)
3. Добавить `modules.add(new ТвойМодуль());` в `ModuleManager#registerModules`

## Принципиальное ограничение
Этот скелет не содержит и не будет содержать модули, основанные на подмене/подделке
сетевых пакетов для обмана серверной валидации (fly, teleport, reach-килаура через
фейковый rotation и т.п.). Всё, что тут есть и будет добавляться по этой же схеме —
работает через честную клиентскую логику и рендер.
